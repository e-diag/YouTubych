# 🎬 Ютубыч — Умный Telegram-бот для YouTube-сообщества

**Ютубыч** — харизматичный, вежливый и с чувством юмора Telegram-бот на **Go (Golang)**, созданный специально для комьюнити ютуберов и создателей контента.

Его главная цель — **раскручивать людей на общение**, поддерживать активность в чате, отвечать на вопросы по YouTube и запоминать участников (их каналы, тематики и успехи).

---

## 🌟 Ключевые возможности

1. **Раскрутка общения при затишье (6 часов):**
   - Бот отслеживает активность в чате. Если в группе никто не писал в течение 6 часов (настраивается), Ютубыч сам генерирует свежую, острую и интересную тему для обсуждения YouTube-авторами.
2. **Ответы на вопросы с защитой от выдумок (Anti-Hallucination):**
   - Если участник задает вопрос по YouTube, бот отвечает, только если уверен в ответе.
   - Если инфа мутная или Ютубыч не знает ответа — он прямо и с юмором говорит об этом, предлагая обсудить с ребятами в чате.
3. **Реакция на обращение:**
   - Мгновенно откликается, когда к нему обращаются по имени («Ютубыч», «ютубыч»), тегают (`@username_bot`) или делают reply на его сообщение.
4. **Google Search Grounding (Бесплатный поиск в реальном времени):**
   - Использует бесплатный Gemini API с инструментом поиска Google в реальном времени для актуальных новостей YouTube.
   - **Плавный уход от ошибки квоты:** если бесплатные запросы или квоты Google Search исчерпаны, бот **никогда не пишет об ошибках API** в группе. Он плавно переводит тему или честно отвечает по своему опыту.
5. **Обучение и память о пользователях:**
   - Бот слушает чат и автоматически запоминает, кто есть кто (название канала, ниша, примерное число подписчиков, заметки).
   - В SQLite хранится профиль каждого автора, благодаря чему бот обращается к участникам персонально.
6. **Админ-команды в ЛС владельца:**
   - Обучение новым фактам вручную (`/learn`).
   - Просмотр базы авторов (`/users`).
   - Статистика активности и принудительный вброс темы (`/topic`, `/status`).

## 🛡️ Безопасность и защита от угроз

Проект спроектирован с упором на максимальную безопасность:

* **Изоляция чата (Scope Isolation):**
  - Бот отвечает **строго в одном разрешенном чате** (`ALLOWED_CHAT_ID`).
  - При попытке добавить бота в чужую группу, Ютубыч немедленно покидает её (`LeaveChat`), предотвращая утечку квот и несанкционированный доступ.
* **Изоляция ЛС (Owner-Only DM):**
  - В личных сообщениях бот принимает команды **только от владельца** (`OWNER_TG_ID`). Сообщения от посторонних пользователей в ЛС блокируются.
* **Защита от спама и DoS (Rate Limiting):**
  - Индивидуальный кулдаун на пользователя (по умолчанию 15 секунд).
  - Групповой кулдаун между сообщениями бота (по умолчанию 5 секунд).
* **Защита от Prompt Injection / Jailbreak:**
  - Промпты экранируют пользовательский ввод. В системных инструкциях жестко зафиксировано правило никогда не выходить из роли Ютубыча, не исполнять сторонние инструкции и не раскрывать системные промпты.
* **Безопасная БД (SQLite без CGO):**
  - Используется чистый Go-драйвер `modernc.org/sqlite` с параметризованными SQL-запросами (защита от SQL Injection). Компилируется на любой ОС без C-компилятора.

## ⚙️ Установка и запуск

### 1. Подготовка ключей и настроек

1. **Telegram Bot Token:**
   - Откройте бота [@BotFather](https://t.me/BotFather) в Telegram.
   - Создайте бота командой `/newbot` и сохраните выданный токен.
   - **ВАЖНО для работы в группе:** В `@BotFather` перейдите в `Bot Settings` -> `Group Privacy` -> выберите `Turn off`. Это позволит боту видеть вопросы в чате, а не только команды со слэшем.
2. **Gemini API Key:**
   - Перейдите в [Google AI Studio](https://aistudio.google.com/) и создайте бесплатный API ключ.
3. **Telegram Chat ID группы:**
   - Добавьте в группу бота вроде `@RawDataBot` или перешлите сообщение из группы в `@userinfobot`, чтобы узнать отрицательный ID супергруппы (обычно начинается с `-100...`).
4. **Ваш Telegram ID:**
   - Напишите боту `@userinfobot` в Telegram, чтобы узнать свой личный числовой ID.

### 2. Настройка файла окружения

Скопируйте пример файла конфигурации:

```bash
cp .env.example .env
```

Заполните переменные в `.env`:

```env
TELEGRAM_BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
GEMINI_API_KEY=AIzaSy...
GEMINI_MODEL=gemini-2.0-flash
ALLOWED_CHAT_ID=-1001234567890
OWNER_TG_ID=987654321
SILENCE_DURATION=6h
USER_COOLDOWN=15s
GROUP_COOLDOWN=5s
DATABASE_PATH=youtubych.db
```

---

### 3. Сборка и запуск

#### Локальный запуск (Windows / Linux / macOS):
```bash
# Сборка бинарника
go build -o youtubych ./cmd/bot

# Запуск
./youtubych
```

#### Запуск в фоновом режиме на Linux сервере (через Systemd):
Создайте файл сервиса `/etc/systemd/system/youtubych.service`:

```ini
[Unit]
Description=YouTubych Telegram Bot
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/youtubych
ExecStart=/opt/youtubych/youtubych
Restart=always
RestartSec=5
EnvironmentFile=/opt/youtubych/.env

[Install]
WantedBy=multi-user.target
```

Запустите сервис:
```bash
sudo systemctl daemon-reload
sudo systemctl enable youtubych
sudo systemctl start youtubych
sudo systemctl status youtubych
```

## 🛠️ Команды владельца в ЛС

Напишите боту в личные сообщения:

* `/status` — аптайм, количество обработанных сообщений, статус активности в группе.
* `/topic` — принудительно сгенерировать тему и отправить в чат прямо сейчас.
* `/users` — показать список запомненных ютуберов, их каналы и тематики.
* `/learn <текст>` — обучить бота новому правилу или факту (например: `/learn Для Shorts важен retention выше 80%`).
* `/facts` — посмотреть сохраненные факты.
* `/search <запрос>` — проверить, как работает живой поиск Google через Gemini.
